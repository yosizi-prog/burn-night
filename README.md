# Burn Night

手放したいことを紙に書いて、焚き火にくべる。灰は星になって、夜空に残る。

燃やした言葉は、この端末の夜空にだけ星として残ります。ほかの人と共有されることはありません。

Write down what you want to let go of, and feed it to the fire. The ashes become stars, and stay in the night sky.

- 薪をくべて火を育てる
- 言葉を書いて燃やすと、星が1つ生まれる
- 10枚で小さな星座に、50枚で夜空が少し明るくなる
- 競争なし、失敗なし。ただ火のそばにいるゲーム
